Install

Two commands and a config file. Nothing to deploy — the server runs on your machine, against your vault.

1 · Run the wizard

bash
$ npx obsidian-agent-connector init

Path to your Obsidian vault: ~/Obsidian/Personal
Vault name [Personal]:
Daily notes folder [01-Daily/]:
Name this agent connection [Claude Code]:

✓ Vault registered: Personal → /home/you/Obsidian/Personal
✓ Found 1,284 notes in 37 folders
✓ API key generated: sk-4f2a…9c1e
  (stored in ~/.obsidian-agent/config.json)

The wizard writes ~/.obsidian-agent/config.json. That file is the whole configuration — vaults, keys, permissions, settings. No database, no account.

2 · Point your agent at it

Recommended: stdio. Your MCP client launches the server itself, so there's nothing to keep running.

{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": ["obsidian-agent", "--mcp"]
    }
  }
}

Or over HTTP, when the dashboard is already running and you want several agents on one server:

…

Claude Code, one-liner: claude mcp add obsidian -- npx obsidian-agent-connector --mcp

3 · Test the connection

bash
$ npx obsidian-agent-connector doctor
✓ Config file present (~/.obsidian-agent/config.json)
✓ Vault readable: /home/you/Obsidian/Personal (1284 notes)
✓ Agent connections: 1
✓ Tool list_notes works
✓ Tool get_tags works
✓ Tool search_notes works

$ npx @modelcontextprotocol/inspector npx obsidian-agent-connector --mcp
# inspector opens and lists all nine tools

4 · Activate your license

The free tier gives you 50 queries a month, one vault, one agent — enough to try it. Paid keys unlock the rest.

Or from the terminal: obsidian-agent license set <key>

Or use the Obsidian plugin

A community plugin that bundles this server is on the roadmap — one-click install from Obsidian's Community Plugins browser. Until then the MCP server is the supported path, and it works with every MCP client, not just Obsidian.
