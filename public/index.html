Nine tools, one server

Standard MCP, so any compliant client discovers them automatically. Notes are also exposed as resources under obsidian://{vault}/{path}.

{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": ["obsidian-gate", "--mcp"]
    }
  }
}

Drop that into .mcp.json, Claude Desktop, or Cursor. Prefer HTTP? Point the client at http://localhost:3100/mcp with your API key.

  • list_notesList notes in a vault folder
  • read_noteFull content + parsed frontmatter
  • search_notesFull-text search across the vault
  • create_noteNew note with frontmatter template
  • update_noteOverwrite or append to a note
  • get_backlinksEvery note linking to this one
  • get_tagsAll tags across the vault, with counts
  • get_daily_noteGet or create the daily note
  • create_linkAdd a [[wikilink]] between notes
